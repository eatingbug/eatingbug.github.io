---

주간 글쓰기 루틴의 오늘 몫을 진행한다. 규칙과 금지선은 `CLAUDE.md`, 용어는 `CONTEXT.md`를 따른다.

## 0. 먼저 상태 파악

```bash
date "+%Y-%m-%d %A ISO=%G-W%V"
gh issue list --state open --limit 20
```

이번 주 주간 이슈(`[Wnn] …`)를 찾아 `gh issue view <n> --comments`로 지금까지 쓴 문단과 하위주제를 확인한다.
주간 이슈가 없으면 그것부터 만든다(아래 "주말" 절차의 다음 주 세팅과 동일).

**ISO 주차가 4의 배수인 주(W36, W40, W44…)의 주말이면, 다른 단계보다 먼저 4주 회고를 띄운다.** (아래 "4주 회고")

## 월~목 — 한 문단

1. 오늘 배정된 하위주제를 이슈에서 꺼내 보여준다.
2. **무조사 원칙을 알린다.** 검색·링크 열기 없이 머릿속에 있는 것만으로 10~15분. 이 타이머는 내가 강제할 수 없으므로 지켜진 척 하지 않는다 — 알리고, 막혔다고 하면 그때 몇 분 버텼는지 묻는다.
3. 쓰기 전에 **메모부터** 하게 한다. "이 문단에서 ① 무슨 얘기 ② 무슨 얘기 ③ 이렇게 맺는다" 수준.
4. 문단을 받으면 **문장은 손대지 않고** 다음만 지적한다: 주술 불일치, 한 문장이 너무 길어 끊어야 할 곳, 맞춤법. 내용을 고쳐 쓰거나 예시 문장을 제시하지 않는다.
5. `gh issue comment <n>`으로 이슈에 남긴다. 형식:

```
## 화 8/11 — {하위주제}

{문단}
```

조사를 했다면 문단 끝에 `[조사: 링크]`를 붙인다.

### 막혔다고 할 때

- 10분을 안 버텼으면 더 버티게 한다.
- 버텼으면 `읽을거리` 이슈(`#1`)에서 관련 자료 **1개**를 연결한다. 15분 상한, 하루 총 30분 캡.
- 그래도 안 되면 **다운시프트**: 한 줄만 쓰고 끝낸다. 왜 막혔는지 한 줄을 덧붙이면 금요일 얼개에 쓸모가 있다.
- 몰아쓰기를 제안하지 않는다. 복구 없음이 원칙이다.

## 금 — 333 얼개 + 초고

1. 이번 주 문단 전부와 메모를 이슈에서 모아 보여준다.
2. **얼개를 승재 님이 짜게 한다.** 목차 → 동그라미 → 대시 3층, 개조식. 이때 조사 제한은 없다 — 빈 칸이 보이면 `읽을거리`에서 읽고 채운다.
3. 얼개가 나오면 **검증만** 한다:
   - 동그라미 키워드가 아래 대시들을 대표하는가? (대시를 안 보고 동그라미만 읽어도 흐름이 보여야 한다)
   - 목차별 분량이 균형 잡혔는가?
   - 서론에서 예고하고 결론에서 답하는 **양괄식**인가?
   - 각 장이 **두괄식**으로 시작하는가?
   - 고유명사·숫자·사례가 들어가 구체적인가?
4. 초고는 승재 님이 쓴다. 음슴체로 거칠게 먼저, 문장 완성은 주말로 미룬다.
5. 파일을 만들어 둔다 — `_posts/{그 주 일요일}-{영문슬러그}.md`:

```yaml
---
title: {제목, 회차 표기 없음}
date: {일요일} 21:00:00 +0900
categories: [{주제 카테고리}]
tags: [주간글, ...]
---
```

`future: false`이므로 일요일 전까지는 공개되지 않는다.

## 토·일 — 다듬기 + 발행 + 다음 주 세팅

1. 초고를 두 번 읽으며 **기계적 교정만** 한다: 주술 불일치, 긴 문장 자르기, 맞춤법, 중복.
2. **안전선 확인** — 회사 내부 지표명·수치·아키텍처가 남아 있지 않은지 훑는다.
3. 일요일 밤까지 커밋·푸시. **퀄리티를 이유로 발행을 미루지 않는다.** 이건 심사가 아니라 자동 배출구다.
4. 주간 이슈를 close 한다.
5. **다음 주 세팅** (기존 주간계획 시간에):
   - `글감 노트`(`#3`)에서 주제 1개를 고른다.
   - **하위주제 4개는 승재 님이 먼저 2개 이상 적는다.** 그전에는 후보를 내지 않는다 — 구상 유형(나열형/인과형/예시형/이론형)만 제시해 유도한다. 2개를 적고도 막히면 그때 후보를 제시하고 `읽을거리`에서 재료를 연결한다.
   - `gh issue create --title "[W{nn}] {주제}"` — 본문에 하위주제 4개를 월~목에 배정해 적는다.
   - 몇 개를 스스로 뽑았는지 이슈 본문에 기록한다(예: `자력 3/4`). 이게 회로 계기판이다.

## 4주 회고 (W36, W40, W44…)

지난 4주 주간 이슈를 모아 다음을 **사실만** 보고한다. 격려나 평가는 하지 않는다.

- 쓴 날 / 다운시프트한 날 / 빈 날
- `[조사: …]` 표시 비율 — 줄고 있으면 잠재성에서 바로 인출하게 된 것이다
- 하위주제 자력 개수 추이 (`자력 2/4` → `4/4`)
- 발행 편수

그리고 4주 전 문단 하나와 이번 주 문단 하나를 나란히 보여준다. 판단은 승재 님이 한다.
