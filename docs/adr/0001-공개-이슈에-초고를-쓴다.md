# 공개 리포의 GitHub 이슈에 매일 초고를 쓴다

매일 한 문단 쓰기의 연속성을 지키려면 마찰이 가장 낮은 자리에 써야 하는데, 이미 `읽을거리`·`글감 노트` 이슈를 쓰고 있고 폰으로도 쓸 수 있다는 이유로 주간 이슈 코멘트를 초고 자리로 정했다. 이 리포는 public이므로 다듬지 않은 초고가 작성 즉시 공개된다는 뜻이고, 그 대가로 "거칠게 쓰기"가 위축될 위험과 삭제로도 되돌릴 수 없는 노출 위험을 안는다.

`_writing/` 같은 리포 내 비공개 파일을 쓰는 대안이 있었지만, 노트북 앞에서만 쓸 수 있어 마찰이 올라간다는 이유로 택하지 않았다. 대신 두 가지로 위험을 상쇄한다: 문제되는 코멘트는 수정·삭제하고, **회사 내부 구체(지표명·수치·아키텍처)만은 사후 삭제가 무의미하므로 작성 시점에 배제**한다.

## Consequences

- 성장 기록이 git 히스토리가 아니라 GitHub 이슈에 남는다. 즉 연속성 아카이브가 GitHub에 종속된다.
- 발행된 글(`_posts/`)만 git으로 추적되고, 그 재료가 된 월~목 문단은 리포에 남지 않는다.
